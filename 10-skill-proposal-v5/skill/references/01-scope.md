# 01 — Scope: What a "Proposal" Is Here

Two independent sources converge on the same definition (owner's decision + both
source sets):

> **Proposal = BAB I–III of a skripsi + DAFTAR PUSTAKA.** Literally "a skripsi
> without the results chapters and beyond". No BAB IV (Hasil), no BAB V
> (Kesimpulan/Saran), no Lampiran of results.

Everything a full skripsi would put in later chapters gets **consolidated as
subsections of BAB III** (schedule, budget, risk) or a paragraph in 1.4 (claim
discipline). If the proposal later grows into the full skripsi, those subsections
are what get expanded, and BAB IV+ are added then.

## Default deliverable shape (DPJ/TRSE lineage)

- Title block: main title (ALL CAPS) + `Judul Alternatif 1` + `Judul Alternatif 2`
  — one document = one tool = one proposal.
- **No cover page, no approval sheets, no preface, no abstract** — standing owner
  decision (skip cover). Do not add them unless asked.
- Ends at DAFTAR PUSTAKA (APA 7, hanging indent).
- Page footer `- N -` (profile DPJ) or per profile BD (see 05).

## Bina Darma front matter — only on request

The BD-2022 guideline defines full-laporan front matter (halaman judul, pengesahan,
persetujuan, abstraksi ≤200 words with 3–5 keywords, kata pengantar, daftar
isi/gambar/tabel). For a **proposal** deliverable this is out of scope by default.
If the user asks for an abstract in a proposal, write one paragraph (context → gap →
`Penelitian ini bertujuan untuk …` → method sketch → implication) ≤200 words +
`Kata Kunci:` 3–5 phrases, and flag it as an addition.

## Decisions to lock BEFORE drafting (step 1 of SKILL.md)

Collect from the user or repo context; write unknowns as markers, never invent:

| Decision | Default if user silent |
|---|---|
| Target tool/location/case (e.g., SIBI-only translation) | required, no default |
| Main title + 2 alternatives | derive from title pattern (02), then confirm |
| Scope boundary ("what we stop at") | feasibility-study line (07) |
| Duration | 1 semester (≈4.5 months) |
| Style profile | DPJ-UNM (see 05); BD only if campus = Bina Darma |
| Citation style | APA 7 in-text author-year |
| Language of deliverable | Indonesian (00) |

**Done when:** every decision listed or explicitly marked; zero fabricated facts.

## Placeholder policy

`[PERLU DATA: nama sekolah/lokasi/...]` for anything the user has not supplied.
A proposal full of placeholders is correct; a proposal with invented names is
broken. Keep a placeholder inventory in the final handover so the user can fill
them in one pass.
