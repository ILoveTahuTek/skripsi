# BAB II — Kajian Pustaka / Landasan Teori

BAB II proves the proposal sits on real literature. The university guide's warning is
binding here: **this chapter is not a stack of definitions** — every theory block must
end in a *discussion*, and the chapter must end in the research position. Name may vary
by campus: *Kajian Pustaka*, *Landasan Teori*, *Tinjauan Pustaka*, *Kajian Teori* —
follow the user's guide, structure below is the same.

## Chapter skeleton

1. **Domain block** (2.1) — the concrete world object (plant, disease, warehouse,
   village, school) with cited facts.
2. **Technology/component blocks** (2.2 … 2.n) — one subsection per major concept,
   ordered as they appear in the system pipeline, not alphabetically.
3. **Penelitian Terdahulu** — prior research compared, ending in the gap.
4. **(Optional) Kerangka Pemikiran / Kerangka Teori** — 1 paragraph + 1 figure tying it
   together (only if the campus template requires it).

## 2.1 Anatomy of one theory block (per subsection)

Each block is 2–5 paragraphs in this order:

1. **Definition** with citation: `Menurut [Nama] ([tahun]), [istilah] adalah [definisi].`
   or `[Istilah] merupakan [definisi] yang [konteks pemakaian] ([Nama], [tahun]).`
   One definition per concept — if three authors define it, pick one and cite the
   others only if they differ usefully: `Definisi serupa dikemukakan oleh [Nama]
   ([tahun]).`
2. **Decomposition** — components/types/criteria: `Komponen [X] menurut [sumber]
   terdiri atas (1) …, (2) …, dan (3) ….` or `[X] dibedakan menjadi beberapa jenis,
   yaitu …`
3. **Working principle / mechanism** — how it behaves in THIS research's context:
   `Prinsip kerja [X] adalah …` · `[X] bekerja dengan cara …`
4. **Discussion / relevance** (mandatory, the step the corpus skips most): `Dalam
   penelitian ini, [X] digunakan sebagai [peran] karena [alasan yang dikaitkan pada
   kebutuhan BAB I].`

**Rules:**

- Cited definition ≠ copied paragraph. Paraphrase; quote verbatim only with quotes
  and page number.
- Foreign terms italic on every use (`*Internet of Things*`, `*machine learning*`);
  absorbed KBBI terms upright (`mikrokontroler`). Build the term list here.
- Figure references: `Gambar 2.1 menunjukkan …` / `… seperti ditunjukkan pada Gambar
  2.1.` — figure caption BELOW the figure, `Gambar 2.1 Judul singkat`.
- No bullet lists inside theory prose — sentences and paragraphs only (lists are for
  BAB III procedures).

## 2.2 Reporting-verb bank

Rotate accurately; do not write *mengatakan* five times:

| Source did this | Verb |
| --- | --- |
| produced a definition/classification | mendefinisikan, mengklasifikasikan, membagi |
| measured something | mengukur, menemukan, melaporkan |
| built a system | merancang bangun, membangun, mengimplementasikan |
| proposed a method | mengusulkan, memperkenalkan, mengembangkan |
| compared X vs Y | membandingkan, mengevaluasi |
| extended prior work | memperluas, memodifikasi, menyempurnakan |
| contradicted | membantah, mempertanyakan |
| surveyed the field | meninjau, merangkum |

Citation placement: narrative for source-specific claims (`Wibowo dkk. [3] mengukur …`),
parenthetical for established facts (`… (Krug, 2006).`).

## 2.3 Penelitian Terdahulu

**Shape (corpus standard):** an intro sentence + a comparison table + a synthesis
paragraph ending in the gap.

- Intro: `Penelitian ini disusun dengan mempertimbangkan penelitian sebelumnya yang
  relevan dengan topik [topik].` / `Beberapa penelitian terdahulu yang relevan dengan
  penelitian ini diuraikan sebagai berikut.`
- Table columns: `Tabel 2.1 Penelitian Terdahulu` → No. · Peneliti (Tahun) · Judul ·
  Hasil · Relevansi. 3–6 rows. Every row = a REAL, verified study
  (`[PERLU RUJUKAN: …]` if unverified — never pad with invented studies).
- **Synthesis paragraph (mandatory):** group by finding, not by source:
  `Penelitian terhadap [X] telah banyak dilakukan. [Nama] ([tahun]) menerapkan [A]
  untuk [hasil]; [Nama] ([tahun]) memperluasnya dengan [B]. Namun, dari penelitian
  tersebut belum ada yang menerapkan [C] pada [konteks spesifik pengguna]. Oleh karena
  itu, penelitian ini menggabungkan [C] dengan [A/B] untuk [konteks].`

**Gap statement rules:**

- The gap must be *positive-and-specific*: what combination/context/parameter has not
  been tried — traceable to the table rows above it.
- Never `belum ada penelitian tentang X` unless the literature was actually searched.
- The gap must answer the "why now, why me" a penguji asks in sempro.

## 2.4 Kerangka pemikiran (if required)

One paragraph + one diagram: `Berdasarkan kajian pustaka di atas, penelitian ini
dilakukan melalui tahapan [ringkas]. Gambar 2.x menunjukkan alur pemikiran penelitian.`
Keep it a summary of BAB II → BAB III linkage, not new theory.
